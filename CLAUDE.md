# CLAUDE.md

Ce projet utilise [AGENTS.md](AGENTS.md) comme source de vérité pour les règles, contraintes et comportements attendus.

**Lire [AGENTS.md](AGENTS.md) avant toute action.** Toutes les règles qui s'y trouvent s'appliquent à Claude Code au même titre qu'aux autres agents.

Points critiques à ne jamais oublier (détaillés dans AGENTS.md) :
- Jamais d'écriture sur le disque source.
- Jamais de restauration sur le disque source.
- Toute action risquée doit être signalée à l'utilisateur.
- Toute décision importante doit être traçable dans les logs.
- Réfléchir avant de coder, simplicité d'abord, changements chirurgicaux, exécution orientée objectif.
